<h1 align="center">🏠 House Price Prediction Web Application</h1>

<p align="center">
A Machine Learning web application that predicts house prices using Flask and Linear Regression.
</p>

<hr>

<h2>📌 Project Overview</h2>
<p>
This project predicts house prices based on user inputs such as bedrooms, bathrooms, area, and other features.
It uses a trained <b>Linear Regression</b> model and provides real-time predictions through a web interface.
</p>

<h2>💡 Features</h2>
<ul>
  <li>✔ User-friendly interface</li>
  <li>✔ Real-time price prediction</li>
  <li>✔ Machine Learning model integration</li>
  <li>✔ Responsive design using Bootstrap</li>
  <li>✔ End-to-end ML project</li>
</ul>

<h2>🛠️ Technologies Used</h2>
<p>
Python | Flask | Scikit-learn | NumPy | Pandas | HTML | CSS | Bootstrap
</p>

<h2>⚙️ How It Works</h2>
<ol>
  <li>User enters house details</li>
  <li>Data is sent to Flask backend</li>
  <li>ML model processes the input</li>
  <li>Prediction is generated</li>
  <li>Result is displayed on the webpage</li>
</ol>

<h2>📊 Machine Learning Model</h2>
<ul>
  <li><b>Algorithm:</b> Linear Regression</li>
  <li><b>Type:</b> Supervised Learning</li>
  <li><b>Purpose:</b> Predict continuous house prices</li>
</ul>
