    <h1>🏠 House Price Prediction Web Application</h1>
    <p>A Machine Learning-based web application that predicts house prices based on user inputs using Flask.</p>

    <h2>📌 Project Overview</h2>
    <p>
        This project predicts house prices based on features like bedrooms, bathrooms, area, and other property details.
        It uses a trained <b>Linear Regression model</b> and provides real-time predictions through a web interface.
    </p>

    <h2>💡 Features</h2>
    <ul>
        <li>User-friendly web interface</li>
        <li>Real-time price prediction</li>
        <li>Machine Learning model integration</li>
        <li>Responsive design using Bootstrap</li>
        <li>End-to-end ML project</li>
    </ul>

    <h2>🛠️ Technologies Used</h2>
    <ul>
        <li>Python</li>
        <li>Flask</li>
        <li>Scikit-learn</li>
        <li>NumPy & Pandas</li>
        <li>HTML, CSS, Bootstrap</li>
    </ul>

    <h2>⚙️ How It Works</h2>
    <ol>
        <li>User enters house details</li>
        <li>Data is sent to Flask backend</li>
        <li>ML model processes input</li>
        <li>Prediction is generated</li>
        <li>Result is displayed on webpage</li>
    </ol>

    <h2>📊 Machine Learning Model</h2>
    <ul>
        <li>Algorithm: Linear Regression</li>
        <li>Type: Supervised Learning</li>
        <li>Purpose: Predict house prices</li>
    </ul>
